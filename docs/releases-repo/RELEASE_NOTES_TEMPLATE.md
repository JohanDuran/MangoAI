Free technical preview of MangoAI for Windows 10/11 (64-bit).

**Install:** download `MangoAI-Setup-<version>.exe`, run it (Windows may show an "unknown publisher" notice: More info -> Run anyway), and follow the first-start checklist. You need the Claude Code CLI signed in; an OpenAI API key is optional (transcription, AI voiceovers and image generation).

**Verify:** compare the SHA-256 of the installer with `SHA256SUMS.txt`.

**Report a problem:** File -> Save diagnostics... in the app, then attach the file to a new issue.

See the repository README for requirements, privacy, and known limits.
